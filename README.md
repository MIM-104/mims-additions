# MIM’s Additions

A torture addon for **Nomifactory CEu**. More complicated crafting, harsher progression, and a factory that becomes increasingly difficult to keep running.

## Features

- **Firmware:** hand program circuits at the Firmware Workbench, then automate programming with the Firmware Synthesis Array
- **Progressive penalties:** machine wear and increasing power demands make expansion more expensive as you progress
- **Factory disruptions:** Blood Moons, shuffled storage, wandering machines, and more
- **New machinery:** Supreme singleblocks, custom microminers, and additional multiblocks
- **Materials and recipes:** Epsteinium, Inconel 600, and more demanding endgame crafting

## Download

The ready-to-play **JAR** will be available under **Releases**, with source offered separately.

Requires **Minecraft 1.12.2** and the complete **Nomi-CEu 1.7.5** modpack.
